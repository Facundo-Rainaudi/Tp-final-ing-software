# Tp-final-ing-software

# Turnos por área

Módulo del sistema interno de Gestión de Turnos para atención al público.
Permite registrar, listar, cancelar y modificar turnos por área o servicio,
ver la disponibilidad de horarios y auditar cada acción.

## Funcionalidades
- Registrar y listar turnos por área
- Disponibilidad de horarios
- Cancelar y modificar turnos
- Persistencia en base de datos
- Auditoría (fecha, usuario, acción)
